# Super Mario Galaxy

Projeto inspirado no universo de **Super Mario Galaxy**, desenvolvido como projeto de estudo e prática em desenvolvimento web/game development.

> Projeto independente e não oficial. Super Mario Galaxy e seus personagens são propriedades de seus respectivos detentores de direitos.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de explorar conceitos de programação, desenvolvimento de interfaces, lógica de jogo e organização de código utilizando tecnologias modernas.

A proposta é transformar a inspiração visual e conceitual de Super Mario Galaxy em uma experiência interativa desenvolvida por código.

## Objetivos

- Praticar desenvolvimento de aplicações interativas
- Trabalhar com lógica e organização de código
- Desenvolver interfaces inspiradas em jogos
- Aprimorar conceitos de JavaScript/TypeScript
- Praticar estruturação e manutenção de projetos
- Aplicar conceitos de Git e GitHub em um projeto completo

## Como executar

Clone o repositório:

```bash
git clone https://github.com/DUCAT1-DEV/super-mario-galaxy.git
```

Entre na pasta:

```bash
cd super-mario-galaxy
```

Instale as dependências, caso existam:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
